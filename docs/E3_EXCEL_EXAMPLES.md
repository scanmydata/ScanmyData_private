# Κανόνες Εισαγωγής & Επεξεργασίας

## Κανόνας 1: Έλεγχος Υπολοίπου
```
Για κάθε λογαριασμό:
Υπόλοιπο = Χρέωση - Πίστωση
```

## Κανόνας 2: Μεταφορά στο E3
```
ΑΝ Κωδικός E3 = -1:
   → Ποσό E3 = κενό ή 0

ΑΛΛΙΩΣ ΑΝ Κωδικός E3 ≥ 0:
   → Ποσό E3 = ABS(Υπόλοιπο)
```

## Κανόνας 3: Επαληθεύσεις (Γ Κατηγορίας)
```
Για κάθε λογαριασμό:

1. Ελέγχου ότι Τύπος Υπολοίπου (G) ταιριάζει με Ομάδα ΕΛΠ (C):
   - Ομάδα 1,2,3: Αναμένεται Χρεωστικό ή Πιστωτικό (ανάλογα)
   - Ομάδα 4,5: Αναμένεται Πιστωτικό
   - Ομάδα 6: Αναμένεται Χρεωστικό
   - Ομάδα 7: Αναμένεται Πιστωτικό

2. Αν Τύπος Υπολοίπου ≠ αναμενόμενο → ΠΡΟΕΙΔΟΠΟΙΗΣΗ
```

## Κανόνας 4: Σύμβαση Χ/Π
```
Για κάθε Ποσό E3:

Σύμβαση Χ/Π δείχνει πώς ερμηνεύεται το ποσό:
- Χρέωση = Αύξηση στο E3 (π.χ. έξοδα, αγορές)
- Πίστωση = Μείωση ή εισόδημα (π.χ. έσοδα, αποσβέσεις)
```
