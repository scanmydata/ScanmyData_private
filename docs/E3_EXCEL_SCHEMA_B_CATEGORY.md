# Excel Schema - Β Κατηγορίας (Απλογραφία/Βάση Ισοζυγίου)

## Περιγραφή
Για τους πελάτες **Β κατηγορίας** (Απλογραφία ή ημιδιπλογραφία), τα δεδομένα έρχονται από **Ισοζύγιο**.
Θα χρησιμοποιούμε τη στήλη **ΥΠΟΛΟΙΠΟ** (τελικό ποσό κάθε λογαριασμού) και θα κάνουμε αντιστοίχιση με τα πεδία Ε3.

---

## Δομή Excel - Β Κατηγορίας

### Columns (A-F)
```
| A: Κωδικός Λογαριασμού | B: Περιγραφή | C: Ομάδα ΕΛΠ | D: Χρέωση | E: Πίστωση | F: Υπόλοιπο | G: Κωδικός E3 | H: Περιγραφή E3 | I: Ποσό E3 |
|---|---|---|---|---|---|---|---|---|
| 700101 | Πωλήσεις αγαθών εσωτερικού | 7 | 0,00 | 50000,00 | -50000,00 | 561 | Πωλήσεις αγαθών | 50000,00 |
| 701101 | Πωλήσεις υπηρεσιών | 7 | 0,00 | 25000,00 | -25000,00 | 561 | Πωλήσεις αγαθών | 25000,00 |
| 600101 | Αγορές εμπορευμάτων | 2 | 30000,00 | 0,00 | 30000,00 | 102 | Αγορές εμπορευμάτων | 30000,00 |
| 400101 | Προμηθευτές | 5 | 5000,00 | 35000,00 | -30000,00 | -1 | — | — |
| 300101 | Πελάτες | 3 | 50000,00 | 20000,00 | 30000,00 | -1 | — | — |
```

### Λεπτομέρειες Στηλών

**A: Κωδικός Λογαριασμού**
- Format: Πεντάψηφιος (π.χ. 700101)
- Ομάδα 2-3 ψηφίων → Ομάδα ΕΛΠ (7=Έσοδα, 6=Έξοδα, κλπ)

**B: Περιγραφή**
- Όνομα λογαριασμού (ελεύθερο κείμενο)

**C: Ομάδα ΕΛΠ**
- 1 = Πάγια
- 2 = Αποθέματα
- 3 = Χρηματοοικονομικά
- 4 = Καθαρή Θέση
- 5 = Υποχρεώσεις
- 6 = Έξοδα κατ' Είδος
- 7 = Έσοδα κατ' Είδος
- 0 = Πληροφοριακοί

**D: Χρέωση**
- Σύνολο χρεωστικών κινήσεων

**E: Πίστωση**
- Σύνολο πιστωτικών κινήσεων

**F: Υπόλοιπο** ← **ΤΟ ΠΟΣΟ ΓΙΑ E3!**
- `Υπόλοιπο = Χρέωση - Πίστωση`
- Αν είναι θετικό → χρεωστικό υπόλοιπο
- Αν είναι αρνητικό → πιστωτικό υπόλοιπο

**G: Κωδικός E3**
- Ο κωδικός Ε3 που αντιστοιχεί ο λογαριασμός
- **-1** = Δεν πάει στο Ε3 (π.χ. Πελάτες, Προμηθευτές, Ταμείο δεν πάνε απ' ευθείας)
- **Κενό ή null** = Άγνωστη αντιστοίχιση

**H: Περιγραφή E3**
- Όνομα της κατηγορίας Ε3 (πληροφοριακό)

**I: Ποσό E3** ← **ΤΟ ΤΕΛΙΚΟ ΠΟΣΟ**
- Λαμβάνει τιμή από **F: Υπόλοιπο** αν `G ≠ -1`
- Αλλιώς, άδειο ή 0

## Λογική Επεξεργασίας

```
ΓΙΑ κάθε σειρά στο Excel:

1. Διάβασε: Κωδικός Λογαριασμού (A), Ομάδα ΕΛΠ (C), Υπόλοιπο (F), Κωδικός E3 (G)

2. ΑΝ Κωδικός E3 (G) = -1:
   → ΠΑΛΙΑ: Δεν μεταφέρεται στο E3

3. ΑΝ Κωδικός E3 (G) = κενό ή null:
   → ΠΡΟΣΟΧΗ: Άγνωστη αντιστοίχιση, πιθανό σφάλμα δεδομένων

4. ΑΝ Κωδικός E3 (G) = ενεργή τιμή (π.χ. 561, 102, κλπ):
   → ΜΕΤΑΦΕΡΕ: Ποσό E3 = Υπόλοιπο (F)
   → ΕΙΣΑΙ: Κωδικό E3 = G, Ποσό = F

5. ΕΛΕΓΧΟΣ ΟΜΑΔΑΣ: Επαληθεύστε ότι το Υπόλοιπο (F) είναι θετικό (χρέωση) ή αρνητικό (πίστωση) όπως αναμένεται για την Ομάδα ΕΛΠ (C)
   - Ομάδες 1,2,3 (Ενεργητικό): Χρεωστικά υπόλοιπα
   - Ομάδες 4,5 (Παθητικό): Πιστωτικά υπόλοιπα
   - Ομάδες 6,7 (Αποτελέσματα): Ανάλογα τη φύση
```

## Παράδειγμα Ολοκληρωμένης Σειράς

### Μεταφορά Ποσών

**Έσοδα (Ομάδα 7):**
```
Κωδικός: 700101
Περιγραφή: Πωλήσεις αγαθών εσωτερικού
Ομάδα ΕΛΠ: 7
Χρέωση: 0,00
Πίστωση: 50000,00
Υπόλοιπο: -50000,00 (αρνητικό = πιστωτικό, που είναι σωστό για έσοδα)

→ Κωδικός E3: 561 (Πωλήσεις αγαθών)
→ Ποσό E3: 50000,00 (απόλυτη τιμή του υπολοίπου)
```

**Αποθέματα (Ομάδα 2):**
```
Κωδικός: 600101
Περιγραφή: Αγορές εμπορευμάτων
Ομάδα ΕΛΠ: 2
Χρέωση: 30000,00
Πίστωση: 0,00
Υπόλοιπο: 30000,00 (θετικό = χρεωστικό, σωστό για αγορές)

→ Κωδικός E3: 102 (Αγορές εμπορευμάτων)
→ Ποσό E3: 30000,00 (ακριβώς το υπόλοιπο)
```

**Πελάτες (Ομάδα 3 - ΔΕΝ πάει στο E3):**
```
Κωδικός: 300101
Περιγραφή: Πελάτες
Ομάδα ΕΛΠ: 3
Χρέωση: 50000,00
Πίστωση: 20000,00
Υπόλοιπο: 30000,00

→ Κωδικός E3: -1 (ΔΕΝ ΜΕΤΑΦΕΡΕΤΑΙ)
→ Ποσό E3: — (κενό)
```

## Σημαντικές Σημειώσεις

✅ Για Β κατηγορίας: Χρησιμοποιούμε **ΠΑΝΤΑ** τη στήλη **Υπόλοιπο (F)**
✅ Μόνο αν `Κωδικός E3 ≠ -1` → Μεταφορά
✅ Προσοχή στις απόλυτες τιμές (αρνητικά υπόλοιπα σε έσοδα → θετικά στο E3)
✅ Ο έλεγχος ομάδας είναι κρίσιμος (χρέωση vs πίστωση)
