# E3 Check — Σύγκριση Ισοζυγίου με Έντυπο Ε3

> **Σχετικά:** για το wiring των ελέγχων Μισθωτηρίων / Ε9-ΕΝΦΙΑ και τη
> συμπεριφορά της σελίδας (visibility του πίνακα Ε3, refresh των
> αποθηκευμένων PDF στην εναλλαγή πελάτη, ατομικός-only PDF retention,
> bulk summary με ποσά) δες
> [`E3_BRAIN_WIRING_NOTES_2026-06-05.md`](./E3_BRAIN_WIRING_NOTES_2026-06-05.md).

## Σκοπός

Η λειτουργία **E3 Check** επιτρέπει στον χρήστη να ανεβάσει το ισοζύγιο του
λογιστηρίου (Excel, Γ Κατηγορίας) και να λάβει αυτόματα:

- Τα ποσά ανά κωδικό Ε3 (χρεωστικά/πιστωτικά ανάλογα με τον τύπο ισοζυγίου)
- Πλήρεις ελληνικές περιγραφές από τους επίσημους Πίνακες Ε3 2025
- Ομαδοποίηση ανά πίνακα (Ζ1, Ζ2, Ζ3, Δ, κ.λπ.)

## Υποστηριζόμενες Μορφές Excel

- `.xls` / `.xlsx`
- Αναγνωρίζει αυτόματα το sheet και τη γραμμή επικεφαλίδων
- Αναμενόμενες στήλες: `Κωδικός`, `Χρέωση`, `Πίστωση`, `Υπόλοιπο`, `Πεδίο Εντύπου Ε3`
- Η στήλη `Περιγραφή` είναι προαιρετική

## Λογική Ανοικτού / Κλειστού Ισοζυγίου

### Ανοικτό ισοζύγιο

Τα αποτελέσματα χρήσης βρίσκονται ακόμα στους λογαριασμούς ομάδων 6 & 7.

```
Ποσό Ε3 = ABS(Υπόλοιπο)
```

### Κλειστό ισοζύγιο (χρεοπιστωμένο)

Έχει γίνει εγγραφή κλεισίματος: οι λογαριασμοί ομάδας-6 έχουν **Υπόλοιπο ≈ 0**
αλλά και Χρέωση > 0 και Πίστωση > 0.

```
Ομάδα-6 (Έξοδα)  → Ποσό = Χρέωση   (πραγματικά έξοδα)
Ομάδα-7 (Έσοδα)  → Ποσό = Πίστωση  (πραγματικά έσοδα)
Λοιποί λογ/μοί   → Ποσό = ABS(Υπόλοιπο)
```

**Κριτήριο ανίχνευσης κλεισίματος:**
> ≥ 50% των leaf-λογαριασμών ομάδας-6 έχουν `|Υπόλοιπο| < 0.01` ΚΑΙ
> `Χρέωση > 0` ΚΑΙ `Πίστωση > 0`

## Χαρτογράφηση E3 (`e3_field_map.py`)

Καλύπτει **όλους** τους κωδικούς Ε3 2025 από τα επίσημα PDFs:

| Πίνακας | Κωδικοί | Περιεχόμενο |
|---------|---------|-------------|
| Δ1–Δ5   | 100–401 | Πωλήσεις & Κόστος (Εμπορική/Παραγωγική/Αγροτική/Υπηρεσίες) |
| Δ6–Δ15  | 120–529 | Μικτό κέρδος, EBITDA, Τόκοι, Φορολογητέο αποτέλεσμα |
| Ε       | 700–733 | Προσωρινές Διαφορές (Λογιστική vs Φορολογική Βάση) |
| ΣΤ      | 140–555 | Φορολογητέα κέρδη ατομικών |
| Ζ1      | 160–570 | Σύνολο Εσόδων |
| Ζ2      | 180–590 | Σύνολο Εξόδων |
| Ζ3      | 195–999 | Πάγια, Επιδοτήσεις, ΕΦΚ |

### Υποκωδικοί (decimal)

Ο κωδικός `185.011` διαβάζεται ως:
- Κύριος κωδικός: `185` → "Διάφορα λειτουργικά έξοδα — Εμπορική"
- Υποκωδικός: `011` → "Ενέργεια"

### Public API του module

```python
from e3_field_map import lookup, describe, group_by_table

info = lookup(185.011)
# → {"code": 185, "sub_code": "011", "label": "...", "sub_label": "Ενέργεια",
#    "table": "Ζ2", "activity": "commercial", "full_description": "..."}

text = describe(185.011)
# → "Διάφορα λειτουργικά έξοδα — Εμπορική / Ενέργεια"

grouped = group_by_table(e3_totals_list)
# → {"Ζ1": [...], "Ζ2": [...], ...}
```

## Module `e3_processor.py` — Public API

```python
from e3_processor import process_excel_file

result = process_excel_file("/path/to/isozygio.xls")
if result["ok"]:
    print(result["is_closed_balance_sheet"])
    for entry in result["e3_totals"]:
        print(entry["e3_code"], entry["amount"], entry.get("description"))
```
