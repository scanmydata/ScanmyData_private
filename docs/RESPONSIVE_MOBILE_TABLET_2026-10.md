# Κινητά / tablet — responsive στρώμα (10/2026)

## Τι άλλαξε

### Κοινά για όλες τις σελίδες (`base.html`)
- **`static/responsive.css`** φορτώνεται μετά τα `app.css`/`shell.css` και πριν την Tailwind. Αν χρειάζεται να νικήσει utility της Tailwind, χρησιμοποιεί `html body …` ή `!important`.
- **Κεφαλίδα ≤1280px:**
  - Πλέγμα με λογότυπο και «☰ Μενού» στην πρώτη σειρά.
  - Η πλοήγηση σε μία γραμμή με οριζόντια κύλιση (swipe). Το ενεργό κουμπί έρχεται αυτόματα σε θέα.
  - Ενεργός πελάτης, ομάδα και χρήση σε δική τους σειρά.
- **Κεφαλίδα ≤768px:** δεν μένει καρφωμένη στην κορυφή και το λογότυπο μικραίνει. Τα μεγάλα ονόματα πελατών κόβονται με «…».
- **Side menu:** απέκτησε και τον σύνδεσμο **Admin** για admins, γιατί στο κινητό το κουμπί του header μπορεί να μη φαίνεται.
- **Πίνακες:** το **`static/js/responsive.js`** (φορτώνεται μία φορά, εκτός `#appShell`) τυλίγει σε `<div class="rsp-scroll">` μόνο όσους πίνακες *δεν χωράνε*, ώστε να κυλούν οριζόντια μέσα στη θέση τους.
  - Οι πίνακες που χωράνε δεν αγγίζονται, άρα η desktop εμφάνιση μένει ίδια.
  - Εξαίρεση γίνεται με `data-no-rsp`.
  - Ο έλεγχος ξανατρέχει σε partial navigation, AJAX, άνοιγμα modals και resize.
- **Modals (Tailwind `fixed inset-0`, Bootstrap):** η κάρτα δεν ξεπερνά ποτέ το πλάτος/ύψος της οθόνης.
- **Φόρμες:**
  - Τα `select` με μακριές επιλογές δεν σπρώχνουν τη σελίδα.
  - Σε οθόνες αφής, input 16px ώστε το iOS να μην κάνει zoom στο focus.
- **Πλέγματα** `grid-cols-4+` χωρίς breakpoint γίνονται 2 στήλες στα ≤640px. Οι γραμμές εργαλείων με κουμπιά σπάνε σε νέα σειρά.
- **DataTables:** τα στοιχεία «εμφάνιση/αναζήτηση/σελίδες» μπαίνουν το ένα κάτω από το άλλο.
- **Δίχτυ ασφαλείας:** `body { overflow-x: clip }`, ώστε τίποτα να μη σπρώχνει τη σελίδα πλάγια (δεν σπάει τα sticky).
- Μπήκε `meta viewport` στα `options.html` / `viewer.html`.

### Αναζήτηση / Αχαρακτήριστα (Tabulator)
Σε ≤900px οι στήλες παίρνουν `minWidth: 96`. Έτσι ο πίνακας κυλά οριζόντια αντί να στριμώχνει τις στήλες σε «40…».

### Προεπισκόπηση Epsilon (`epsilon_preview.html`) — redesign
- **Κεφαλίδα-κάρτα:** κουμπί επιστροφής, chip ΑΦΜ και πλήθος εγγραφών. Οι ενέργειες (Εξαίρεση ήδη εξαγμένων, Επαναφορά, Λήψη Γέφυρας με μενού μορφών) σπάνε σε σειρές στο κινητό.
- **Σύνολα σε κάρτες:** Καθαρή, ΦΠΑ, Μικτό, Εγγραφές και νέο **«Με ελλείψεις»**. Με κλικ στην κάρτα «Με ελλείψεις» ή στο «Μόνο με ελλείψεις» φαίνονται μόνο όσες εγγραφές μπλοκάρουν τη Strict γέφυρα (CUSTID, χαρακτηρισμοί, λογαριασμοί).
- **Πίνακας (≥900px):**
  - Κυλά μέσα στην κάρτα του και όχι έξω από τη σελίδα.
  - Ενοποιημένες στήλες: «Εκδότης» = όνομα + ΑΦΜ, «Παραστατικό» = Α/Α + είδος.
  - Sticky επικεφαλίδες.
- **Κάρτες (<900px):** μία κάρτα ανά παραστατικό, με ποσά, συναλλασσόμενο, χαρακτηρισμούς, λογαριασμούς, ανάπτυξη γραμμών και Διαγραφή.
  - Ίδια σελίδα, ταξινόμηση και φίλτρο με τον πίνακα.
- Νέα επιλογή εγγραφών ανά σελίδα. Πληροφορίες και σελιδοποίηση στο κάτω μέρος, σε κάθε πλάτος.
- **Ενεργοποίηση της Λήψης Γέφυρας:** ελέγχεται πλέον σε **όλες** τις (μη διαγραμμένες) εγγραφές και όχι μόνο στις φιλτραρισμένες, γιατί η γέφυρα εξάγει όλες τις εγγραφές.
- Τα ονόματα εκδοτών και τα λοιπά πεδία γίνονται HTML-escape.
- Light/dark μέσω CSS μεταβλητών (`--epx-*`). Τα modals γίνονται bottom-sheet στο κινητό.

## Έλεγχος
- Playwright σε 375 / 390 / 768 / 1024 / 1280 / 1366 / 1440px, σε όλες τις κύριες σελίδες:
  - Καμία οριζόντια υπερχείλιση.
  - Το desktop (1440px) χωρίς αλλαγές.
- Λειτουργίες epsilon σε κινητό και desktop: διαγραφή, επαναφορά, φίλτρο ελλείψεων, αναζήτηση, εγγραφές/σελίδα, μενού λήψης.
