## 📖 Γρήγορη Αναφορά

### Β Κατηγορίας - Κρίσιμα Σημεία

| Σημείο | Κανόνας |
|---|---|
| **Ποσό** | Χρησιμοποιείστε τη στήλη ΥΠΟΛΟΙΠΟ (F) |
| **Κωδικός E3** | Από Πίνακες 1-8 του Reference |
| **-1** | ΔΕΝ πάει στο E3 (Πελάτες, Προμηθευτές, κλπ) |
| **Φόρμουλα** | `Ποσό E3 = ABS(Υπόλοιπο)` αν κωδικός ≠ -1 |

### Γ Κατηγορίας - Κρίσιμα Σημεία

| Σημείο | Κανόνας |
|---|---|
| **Ομάδα ΕΛΠ** | ΠΡΕΠΕΙ να ταιριάζει με τον κωδικό λογαριασμού |
| **Συμβάσεις** | Χρέωση/Πίστωση ΠΡΕΠΕΙ να ταιριάζουν με ομάδα |
| **Τύπος Υπολοίπου** | Εξαρτάται από τη Συμβάσεις (Χρ. vs Πι.) |
| **Κωδικός E3** | Από τον Οδηγό ΕΛΠ + Πίνακες Reference |
| **-1** | ΔΕΝ πάει στο E3 (Ομάδες 3, 4, 5 συνήθως) |
| **-2** | Ειδικός (Πίνακας Ε - Φορολογικές Διαφορές) |
| **Φόρμουλα** | `Ποσό E3 = ABS(Υπόλοιπο)` αν κωδικός ≠ -1 |

## 🔍 Παράδειγμα Ολοκληρωμένης Μετατροπής

### Β Κατηγορίας

**Input:**
```
Κωδικός: 700101
Περιγραφή: Πωλήσεις αγαθών εσωτερικού
Ομάδα ΕΛΠ: 7
Χρέωση: 0,00
Πίστωση: 50.000,00
Υπόλοιπο: -50.000,00
```

**Διαδικασία:**
1. Ψάξε κωδικό 700101 → Ομάδα 7 (Έσοδα)
2. Δες Πίνακα 7 (E3_MAPPING_REFERENCE.md)
3. Λογ. 70x → Κωδικός E3 = 561 (Πωλήσεις αγαθών)
4. Ποσό E3 = ABS(-50.000,00) = 50.000,00
5. Σημείωση: Κωδικός 561 ≠ -1 → Πάει στο E3

**Output:**
```
Κωδικός E3: 561
Ποσό E3: 50.000,00
Πίνακας E3: Δ (2.1)
```

### Γ Κατηγορίας

**Input:**
```
Κωδικός: 113
Περιγραφή: Κτήρια
Ομάδα ΕΛΠ: 1
Χρέωση: 100.000,00
Πίστωση: 0,00
Υπόλοιπο: 100.000,00 (Χρεωστικό)
```

**Διαδικασία:**
1. Ψάξε Λογ. 113 → Ομάδα 1 (Πάγια)
2. Δες Πίνακα 1 (E3_MAPPING_REFERENCE.md)
3. Λ.113 (Κτήρια) → Κωδικός E3 = 101 (Αξία Κτήσης Κτηρίων)
4. Σύμβαση Χ/Π: Χρέωση (αξία κτήσης)
5. Ποσό E3 = ABS(100.000,00) = 100.000,00
6. Πίνακας E3 = Ν (Σειρά 1)

**Output:**
```
Κωδικός E3: 101
Ποσό E3: 100.000,00
Πίνακας E3: Ν (Σειρά 1)
Σύμβαση Χ/Π: Χρέωση
```

## ⚠️ Κοινά Σφάλματα & Λύσεις

### Σφάλμα 1: "Πελάτες/Προμηθευτές πάνε στο E3"
❌ **ΛΑΘΟΣ**: Κωδικός E3 = 102 ή άλλος θετικός
✅ **ΣΩΣΤΟ**: Κωδικός E3 = -1 (δεν πάνε)

### Σφάλμα 2: "Αποσβέσεις έχουν θετικό υπόλοιπο"
❌ **ΛΑΘΟΣ**: Λ. 181 (Αποσβέσεις) = 50.000,00 (θετικό)
✅ **ΣΩΣΤΟ**: Λ. 181 = -50.000,00 (πιστωτικό)

### Σφάλμα 3: "Έσοδα με αρνητικό ποσό E3"
❌ **ΛΑΘΟΣ**: Λ. 700 Υπόλοιπο = -250.000,00 → Ποσό E3 = -250.000,00
✅ **ΣΩΣΤΟ**: Λ. 700 Υπόλοιπο = -250.000,00 → Ποσό E3 = ABS(-250.000,00) = 250.000,00

### Σφάλμα 4: "Γ κατηγορίας χωρίς επαλήθευση ομάδας"
❌ **ΛΑΘΟΣ**: Λ. 123 (Κτήρια) με Ομάδα ΕΛΠ = 2
✅ **ΣΩΣΤΟ**: Λ. 123 (Κτήρια) με Ομάδα ΕΛΠ = 1
