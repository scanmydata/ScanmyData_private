## 🔧 Φόρμουλες Excel

### Για Β Κατηγορίας

**Υπόλοιπο (Στήλη F):**
```excel
=D2-E2
```

**Ποσό E3 (Στήλη K):**
```excel
=IF(G2=-1,"",ABS(F2))
```
Ή αν θέλετε ακέραιο 0 αντί κενού:
```excel
=IF(G2=-1,0,ABS(F2))
```

### Για Γ Κατηγορίας

**Υπόλοιπο (Στήλη F):**
```excel
=D2-E2
```

**Τύπος Υπολοίπου (Στήλη G):**
```excel
=IF(F2>0,"Χρεωστικό","Πιστωτικό")
```

**Ποσό E3 (Στήλη L):**
```excel
=IF(H2=-1,"",ABS(F2))
```
Ή αν θέλετε ακέραιο 0:
```excel
=IF(H2=-1,0,ABS(F2))
```

## 🎯 Validation Rules (Excel Data Validation)

### Για Στήλη C (Ομάδα ΕΛΠ)

**Type:** List
**Source:** 1, 2, 3, 4, 5, 6, 7, 0

### Για Στήλη G (Τύπος Υπολοίπου) - Γ Κατηγορίας

**Type:** List
**Source:** Χρεωστικό, Πιστωτικό

### Για Στήλες D, E, F (Αριθμοί)

**Type:** Decimal
**Decimal places:** 2
**Minimum:** 0 (για D, E)
**Allow Negative:** Yes (για F)

## 🔄 Import/Export

### Από Excel → CSV

**Αποθήκευση ως CSV (Excel):**
1. File → Save As
2. Format: CSV (Comma delimited) (.csv)
3. Όνομα: `B_CATEGORY_ISOZYGION_20260519.csv` ή `G_CATEGORY_DIPLOGIAFI_20260519.csv`

**Encoding:** UTF-8 με BOM (για σωστή ελληνικά)

### Από CSV → Excel

**Εισαγωγή CSV (Excel):**
1. File → Open
2. Διαλέξτε το .csv αρχείο
3. Wizard: Delimiter = Comma, Encoding = UTF-8

## ✅ Checklist Ολοκλήρωσης

### Για Β Κατηγορίας

- [ ] Όλες οι στήλες A-K συμπληρωμένες
- [ ] Ομάδα ΕΛΠ (C) = 0-7
- [ ] Χρέωση/Πίστωση (D,E) = αριθμοί > 0
- [ ] Υπόλοιπο (F) = D-E
- [ ] Κωδικός E3 (G) = ενεργό νούμερο ή -1
- [ ] Ποσό E3 (K) = ABS(F) αν G ≠ -1
- [ ] Στήλες H,I,J,L πληροφοριακές (προαιρετικές)

### Για Γ Κατηγορίας

- [ ] Όλες οι στήλες A-M συμπληρωμένες
- [ ] Ομάδα ΕΛΠ (C) = 0-7
- [ ] Χρέωση/Πίστωση (D,E) = αριθμοί > 0
- [ ] Υπόλοιπο (F) = D-E
- [ ] Τύπος Υπολοίπου (G) = Χρ. ή Πι. (ΣΩΣΤΗ συμβάσεις!)
- [ ] Κωδικός E3 (H) = ενεργό νούμερο ή -1
- [ ] Ποσό E3 (L) = ABS(F) αν H ≠ -1
- [ ] Στήλες I,J,K,M πληροφοριακές (προαιρετικές)
- [ ] Επαλήθευση: Ομάδα + Τύπος Υπολοίπου ταιριάζουν (από Οδηγό ΕΛΠ)

## 📞 Γρήγορες Αναφορές

### Στήλες με Data Validation

**Β Κατηγορίας:**
- C (Ομάδα): 0,1,2,3,4,5,6,7
- D,E,F (Αριθμοί): Decimal, 2 δεκαδικά

**Γ Κατηγορίας:**
- C (Ομάδα): 0,1,2,3,4,5,6,7
- G (Τύπος): Χρεωστικό, Πιστωτικό
- D,E,F (Αριθμοί): Decimal, 2 δεκαδικά

### Αυτόματες Στήλες (Formulas)

**Β Κατηγορίας:**
- F (Υπόλοιπο): `=D-E`
- K (Ποσό E3): `=IF(G=-1,"",ABS(F))`

**Γ Κατηγορίας:**
- F (Υπόλοιπο): `=D-E`
- G (Τύπος): `=IF(F>0,"Χρ","Πι")`
- L (Ποσό E3): `=IF(H=-1,"",ABS(F))`
