# E3 — Ε9/ΕΝΦΙΑ ATAK picker, ιδιόχρηση sqm choices & Excel credentials import

Συμπληρωματικά docs για τις νέες λειτουργίες (Ιούνιος 2026) στη σελίδα `/e3_check`.

## 1. Ε9/ΕΝΦΙΑ ATAK picker — multi-ATAK ιδιόχρηση

Στον **Αναλυτικό έλεγχο E3** (ατομικός *και* μαζικός) όταν ενεργοποιηθεί ο
έλεγχος Ε9 και η διεύθυνση δεν βρεθεί σε μισθωτήριο, το brain αντλεί όλα
τα ATAK που έχει ο πελάτης στην ίδια οδό από το εκκαθαριστικό ΕΝΦΙΑ. Για
κάθε ATAK ο parser ([e3/pol_1237_mapping.py](../e3/pol_1237_mapping.py))
αποκωδικοποιεί:

- **Κατηγορία ακινήτου** (στήλη 9 — κωδικοί 1-13, 41-47, 51-52 — βλ.
  ΠΟΛ.1237/2014).
- **Όροφος** (στήλη 11 — Υπόγειο, Ισόγειο, 1ος, 2ος, …).
- **Επιφάνεια κύριων χώρων** (στήλη 12).
- **Αξία ακινήτου** (από το ΕΝΦΙΑ εκκαθαριστικό).
- **Έτος κατασκευής**, **ποσοστό συνιδιοκτησίας**.

### 1.1 Picker UI

Ανοίγει αυτόματα όταν υπάρχει **τουλάχιστον 1 ATAK** (ώστε ο χρήστης να
δηλώσει partial ιδιόχρηση ακόμη και αν το brain βρήκε ένα ακίνητο).
Κάθε γραμμή δίνει:

- Checkbox **«Συμπερίληψη»** — αν αποεπιλεγεί, το ATAK δεν προσμετράται.
- Radio **«Ιδιόχρηση σε όλα τα τμ»** vs **«Μερική ιδιόχρηση»**.
- Πεδίο τμ + γρήγορο κουμπί **«10 τ.μ.»** για συνηθισμένες περιπτώσεις.
- (Όταν `ποσοστό συνιδιοκτησίας < 100%`) checkbox **«Υπάρχει και
  ενοίκιο για το ίδιο ακίνητο»** — το brain επιτρέπει μικτή ιδιόχρηση
  + ενοίκιο για το ίδιο ακίνητο όταν δεν εξαντλείται το 100% της
  κυριότητας.

Ο τύπος υπολογισμού είναι:
```
συμβολή 585.014 = (sqm_used / sqm_total) × αξία_ακινήτου × 3%
σύνολο 585.014  = Σ(όλες οι συμβολές των ενεργών ATAK)
```

### 1.2 Multi-address support (έδρα + υποκαταστήματα)

Όταν ο χρήστης δηλώσει υποκαταστήματα ή το brain τα αντλήσει από ΓΕΜΗ
(`sub_home.py`), ο έλεγχος Ε9 τρέχει για κάθε διεύθυνση χωριστά. Το
brain επιστρέφει `rent_breakdown[i].e9_properties` για κάθε υποκατά-
στημα όταν αυτό λύθηκε μέσω Ε9 × 3%, και ο picker τα ομαδοποιεί σε
**🏢 Έδρα** και **🏬 Υποκατάστημα — <διεύθυνση>** sections, ώστε ο
χρήστης να ρυθμίζει sqm choices ξεχωριστά ανά ATAK.

### 1.3 Persistence (per group / AFM)

Οι επιλογές αποθηκεύονται σε
`data/<group_folder>/e9_choices/<afm>.json`:

```json
{
  "00502842056": {
    "sqm_used": 110.0,
    "has_rental": false,
    "rental_sqm": null,
    "updated_at": "2026-06-22T00:00:00Z"
  }
}
```

Διαχείριση μέσω 2 endpoints (login required, group-scoped):

- `POST /api/e3/etak_choices/get` — `{afm}` → `{ok, choices}`.
- `POST /api/e3/etak_choices/save` — `{afm, choices}` → `{ok, saved}`.

Στην επόμενη χρονιά, όταν ξανατρέξει ο αναλυτικός έλεγχος για τον ίδιο
ΑΦΜ, ο picker pre-fills τις σωσμένες τιμές. Ο χρήστης μπορεί πάντα να
αλλάξει — το checkbox **«Αποθήκευση επιλογών για επόμενα έτη»** είναι
default on.

### 1.4 Bulk (μαζικός) έλεγχος

Στον μαζικό έλεγχο, κάθε client card στο accordion έχει κουμπί
**«🏠 Ρύθμιση ιδιόχρησης (N ΑΤΑΚ)»** όταν το brain βρήκε ATAKs. Ο
picker ανοίγει με τα HQ + branch ATAKs του συγκεκριμένου πελάτη,
ο χρήστης ρυθμίζει, και το σύνολο 585.014 του card ενημερώνεται
ζωντανά. Οι επιλογές αποθηκεύονται με τον ίδιο τρόπο όπως στον
ατομικό.

### 1.5 PDF export

Στο εξαγόμενο PDF αντιπαραβολής (`_brainBulkExportToPdf` —
ισχύει για ατομικό *και* μαζικό όταν είναι ενεργό το checkbox
«Αποθήκευση πίνακα αντιπαραβολής σε PDF») προστέθηκε ενότητα
**«Λεπτομέρειες ΑΤΑΚ από Ε9/ΕΝΦΙΑ (βάσει ΠΟΛ.1237/2014)»** ανά
πελάτη, ομαδοποιημένη σε Έδρα / Υποκατάστημα · <διεύθυνση>, με
στήλες:

| ΑΤΑΚ | Κατηγορία | Όροφος | Επιφάνεια | Αξία ακινήτου | Επιλογή χρήστη | Συμβολή 585.014 |
|------|-----------|--------|-----------|---------------|----------------|------------------|

«Επιλογή χρήστη» δείχνει αν διάλεξε «Όλα τα τμ» ή «Μερική (X / Y τμ)»
και αν έχει σημαδέψει «+ Ενοίκιο για το ίδιο ακίνητο».

## 2. Excel credentials import (Κωδικοί_Υπόχρεων.xlsx)

Στο tab **Αποθηκευμένα** πάνω αριστερά υπάρχει νέο κουμπί
**📤 Εισαγωγή από Excel** δίπλα στο «Ανανέωση/Προβολή». Δέχεται το
λογιστικό αρχείο `Κωδικοί_Υπόχρεων.xlsx` (83-στηλη μορφή
ScanmyData / EasySoft / Epsilon) και κάνει merge:

- Επιλέγεται αυτόματα το πρώτο sheet που έχει στήλη `Α.Φ.Μ.`.
- Διαβάζονται οι στήλες: ΑΦΜ, Επωνυμία/Επώνυμο, Όνομα, Είδος,
  Α.Μ.Κ.Α., **Όνομα χρήστη TAXISNET / Συνθηματικό TAXISNET**,
  **Όνομα χρήστη myData / Api myData**, Δ.Ο.Υ.
- Το **«Είδος»** μεταφράζεται σε «νομική μορφή» (Ατομική / Προσωπική
  Εταιρεία / Νομικό Πρόσωπο).
- Για κάθε ΑΦΜ:
  - Αν δεν υπάρχει στο `e3_company_credentials_store.json`, εισάγεται ως
    νέα εγγραφή.
  - Αν υπάρχει, ενημερώνονται μόνο τα **non-empty** πεδία (ώστε ένα
    μερικώς συμπληρωμένο sheet να μην σβήνει ήδη αποθηκευμένα secrets).
  - 8-ψήφια ΑΦΜ (όπου Excel ξήλωσε το leading zero) γίνονται padded
    σε 9 ψηφία.
- Το checkbox **«Αντικατάσταση υπαρχόντων»** δίπλα στο κουμπί κάνει
  full wipe + import (χρήσιμο για πρώτο upload σε καθαρή ομάδα).

Endpoint: `POST /api/e3/brain/credentials_store/import_excel`
(multipart, field `file`, optional `replace=1`). Επιστρέφει:

```json
{"ok": true, "sheet": "Sheet", "imported": 12, "updated": 4, "skipped": 1, "total": 16, "columns_matched": {...}}
```

Έλεγχοι access: login required + role `admin`/`member` της ενεργής
ομάδας (ή global admin).
