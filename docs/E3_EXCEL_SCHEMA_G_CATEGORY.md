# Excel Schema - Γ Κατηγορίας (Διπλογραφία - Ακολουθώντας Οδηγό ΕΛΠ)

## Περιγραφή
Για τους πελάτες **Γ κατηγορίας** (Διπλογραφία - Τήρηση αναλυτικών βιβλίων κατά ΕΛΠ), τα δεδομένα έρχονται από **Ισοζύγιο Διπλογραφικής Τήρησης**.
Ακολουθούμε **ΑΥΣΤΗΡΑ** τον Οδηγό Μεταφοράς ΕΛΠ→Ε3 που περιγράφει τις Ομάδες 1-7 και τους κανόνες χρέωσης/πίστωσης.

## Λεπτομέρειες Στηλών

### A: Κωδικός Λογαριασμού
- Format: Τριψήφιος ή περισσότερο (π.χ. 113, 181, 201, κλπ)
- Σύμφωνα με τα ΕΛΠ (Ελληνικά Λογιστικά Πρότυπα)

### B: Περιγραφή
- Όνομα λογαριασμού (ελεύθερο κείμενο)

### C: Ομάδα ΕΛΠ
- **1** = Ενσώματα & Άυλα Πάγια Στοιχεία (Ενεργητικό)
- **2** = Αποθέματα
- **3** = Χρηματοοικονομικά Στοιχεία & Προκαταβολές
- **4** = Καθαρή Θέση & Προβλέψεις
- **5** = Υποχρεώσεις
- **6** = Έξοδα κατ' Είδος
- **7** = Έσοδα κατ' Είδος
- **0** = Πληροφοριακοί Λογαριασμοί (Τάξεως)

### D: Χρέωση
- Σύνολο χρεωστικών κινήσεων της χρήσης

### E: Πίστωση
- Σύνολο πιστωτικών κινήσεων της χρήσης

### F: Υπόλοιπο
- `Υπόλοιπο = Χρέωση - Πίστωση`
- Σχεδόν πάντα χρησιμοποιούμε το **Υπόλοιπο 31/12** (τελική κατάσταση)

### G: Τύπος Υπολοίπου
- **Χρεωστικό** = F > 0 (ή F < 0 αν σωστά αρνητικό)
- **Πιστωτικό** = F < 0 (ή F > 0 αν σωστά θετικό)
- Σημαντικό για έλεγχο κανόνων χρέωσης/πίστωσης

### H: Κωδικός E3
- Ο κωδικός Ε3 που αντιστοιχεί ο λογαριασμός
- **-1** = Δεν πάει στο Ε3 (π.χ. Πελάτες, Προμηθευτές, Ταμείο, Τράπεζες)
- **-2** = Ειδικός κωδικός (π.χ. για Πίνακα Ε - Φορολογικές Διαφορές)
- **Κενό** = Άγνωστη αντιστοίχιση
- **Ενεργή τιμή** = π.χ. 101, 102, 561, 581, κλπ

### I: Περιγραφή E3
- Όνομα της κατηγορίας Ε3 (αναφορικό)

### J: Πίνακας E3
- **Δ (ΠίνακαςΤΰπος)** = Πίνακας Δ (Αποτελέσματα κατ' είδος)
  - **1.1** = Ενάρξης αποθεμάτων
  - **1.2** = Αγορές/Παραγωγή χρήσης
  - **1.3** = Λήξης αποθεμάτων
  - **2.1** = Πωλήσεις/Έσοδα
  - **3.1** = Παροχές σε εργαζόμενους
  - **3.2** = Διάφορα λειτουργικά έξοδα
  - **3.3** = Αποσβέσεις
- **Ν (ΣειράX)** = Πίνακας Ν (Πάγια - Ενεργητικό/Διόρθωση)
  - **1** = Αξία Κτήσης vs Σωρευμένες Αποσβέσεις
- **Ζ3** = Πίνακας Ζ3 (Ισολογισμός - Ενεργητικό/Παθητικό)
- **Ε** = Πίνακας Ε (Φορολογικές Διαφορές - αν κωδικός -2)

### K: Σύμβαση Χ/Π
- **Χρέωση** = Το υπόλοιπο πάει ως χρεωστικό στο Ε3
- **Πίστωση** = Το υπόλοιπο πάει ως πιστωτικό στο Ε3
- Σημαντικό για τη σωστή ερμηνεία του ποσού

### L: Ποσό E3
- Το τελικό ποσό που μεταφέρεται στο Ε3
- `Ποσό E3 = ABS(Υπόλοιπο)` (απόλυτη τιμή)
- Αν `Κωδικός E3 = -1` → κενό ή 0

### M: Σημειώσεις
- Ελεύθερες σημειώσεις (π.χ. "Ενσώματα πάγια", "Λειτουργικό έξοδο", κλπ)

## Λογική Επεξεργασίας (Ακολουθώντας Τον Οδηγό)

### Βήμα 1: Χαρακτηρισμός Ομάδας & Ελέγχου Κανόνων

```
ΓΙΑ κάθε σειρά Ισοζυγίου:

1. Διάβασε: Ομάδα ΕΛΠ (C), Χρέωση (D), Πίστωση (E), Υπόλοιπο (F)

2. ΕΛΕΓΧΟΣ ΣΥΜΒΑΣΗΣ ΧΡΕΩΣΗΣ/ΠΙΣΤΩΣΗΣ:
   
   Ομάδα 1 (Πάγια - Ενεργητικό):
   - Κανόνας: Χρέωση = αυξάνει, Πίστωση = μειώνει
   - Αναμενόμενο Υπόλοιπο: Χρεωστικό (F > 0) ή Πιστωτικό (F < 0)
   - Περίπτωση λ.18 (Αποσβέσεις): Πάντα πιστωτικό
   
   Ομάδα 2 (Αποθέματα):
   - Κανόνας: Χρέωση = αγορές + ενάρξης, Πίστωση = λήξης + επιστροφές
   - Αναμενόμενο Υπόλοιπο: Χρεωστικό (F > 0) - κόστος αγορών
   
   Ομάδα 3 (Χρηματοοικονομικά - Ενεργητικό):
   - Κανόνας: Χρέωση = αυξάνει, Πίστωση = μειώνει
   - Αναμενόμενο Υπόλοιπο: Χρεωστικό (F > 0)
   - Δεν πάει Ε3 (πελάτες, ταμείο, τράπεζες κλπ)
   
   Ομάδα 4 (Καθαρή Θέση - Παθητικό):
   - Κανόνας: Πίστωση = αυξάνει, Χρέωση = μειώνει
   - Αναμενόμενο Υπόλοιπο: Πιστωτικό (F < 0) ή Χρεωστικό (αν ζημίες)
   - Μόνο για διπλογραφικά βιβλία (Πίνακας Ζ3)
   
   Ομάδα 5 (Υποχρεώσεις - Παθητικό):
   - Κανόνας: Πίστωση = αυξάνει, Χρέωση = μειώνει
   - Αναμενόμενο Υπόλοιπο: Πιστωτικό (F < 0)
   - Δεν πάει Ε3 (προμηθευτές, ΦΠΑ, δάνεια κλπ)
   
   Ομάδα 6 (Έξοδα κατ' Είδος - Αποτελέσματα):
   - Κανόνας: Χρέωση = πραγματοποιούνται έξοδα, Πίστωση = διορθώσεις ή κλείσιμο
   - Αναμενόμενο Υπόλοιπο: Χρεωστικό (F > 0) - κόστος εξόδων
   
   Ομάδα 7 (Έσοδα κατ' Είδος - Αποτελέσματα):
   - Κανόνας: Πίστωση = πραγματοποιούνται έσοδα, Χρέωση = επιστροφές ή κλείσιμο
   - Αναμενόμενο Υπόλοιπο: Πιστωτικό (F < 0) - κόστος εσόδων
```

### Βήμα 2: Καθορισμός Κωδικού Ε3 & Πίνακα

```
ΑΝ Ομάδα = 1 (Πάγια):
   - Λ.11-17 (Ενσώματα/Άυλα): Κωδικός E3 = 101-107 (αντίστοιχα) → Πίνακας Ν
   - Λ.18 (Αποσβέσεις): Κωδικός E3 = 101-107 (ίδιος με το πάγιο) → Πίνακας Ν
   - → Σύμβαση Χ/Π: Χρέωση για αξία, Πίστωση για αποσβέσεις

ΑΝ Ομάδα = 2 (Αποθέματα):
   - Ενάρξης (1/1): Κωδικός E3 = 201-204 (αντίστοιχα) → Πίνακας Δ (1.1)
   - Αγορές χρήσης: Κωδικός E3 = 102 (Αγορές εμπορευμάτων) ή 202-204 → Πίνακας Δ (1.2)
   - Λήξης (31/12): Κωδικός E3 = 201-204 (αντίστοιχα) → Πίνακας Δ (1.3)
   - Επιστροφές/Εκπτώσεις: Κωδικός E3 = -1 (δεν πάνε) ή ειδικός κωδικός

ΑΝ Ομάδα = 3 (Χρηματοοικονομικά):
   - Κωδικός E3 = -1 (ΔΕΝ ΠΑΝΕ ΣΤΟ E3)
   - Σημείωση: Μόνο για Ισολογισμό (Πίνακας Ζ3) σε διπλογραφικά

ΑΝ Ομάδα = 4 (Καθαρή Θέση):
   - Κωδικός E3 = -1 ή Πίνακας Ζ3 (μόνο διπλογραφία)
   - Σημείωση: Δεν αναλύονται σε Ε3, μόνο σε Πίνακα Ζ

ΑΝ Ομάδα = 5 (Υποχρεώσεις):
   - Κωδικός E3 = -1 (ΔΕΝ ΠΑΝΕ ΣΤΟ E3)
   - Σημείωση: Μόνο για Ισολογισμό (Πίνακας Ζ3) σε διπλογραφικά

ΑΝ Ομάδα = 6 (Έξοδα κατ' Είδος):
   - Μισθοί: Κωδικός E3 = 581 → Πίνακας Δ (3.1)
   - Λειτουργικά: Κωδικός E3 = 585 → Πίνακας Δ (3.2)
   - Αποσβέσεις: Κωδικός E3 = 586 (ή ειδικός) → Πίνακας Δ (3.3)
   - Άλλα: Κωδικός E3 = -1 ή ειδικός

ΑΝ Ομάδα = 7 (Έσοδα κατ' Είδος):
   - Πωλήσεις αγαθών: Κωδικός E3 = 561 → Πίνακας Δ (2.1)
   - Παροχή υπηρεσιών: Κωδικός E3 = 562 → Πίνακας Δ (2.2)
   - Επιχορηγήσεις: Κωδικός E3 = 563 → Πίνακας Δ (2.3)
   - Άλλα: Κωδικός E3 = -1 ή ειδικός

ΑΝ Ομάδα = 0 (Πληροφοριακοί):
   - Μη εκπιπτόμενες δαπάνες: Κωδικός E3 = -2 (ειδικός) → Πίνακας Ε (Φορολογικές Διαφορές)
   - Προσωρινές διαφορές: Κωδικός E3 = -2 → Πίνακας Ε
   - Άλλα: Κωδικός E3 = -1 (δεν αναλύονται)
```

### Βήμα 3: Υπολογισμός Ποσού Ε3

```
ΑΝ Κωδικός E3 (H) = -1:
   → Ποσό E3 = — (κενό)

ΑΝ Κωδικός E3 (H) = -2:
   → Ποσό E3 = ABS(Υπόλοιπο) → Πίνακας Ε

ΑΝ Κωδικός E3 (H) = ενεργή τιμή (π.χ. 101, 561, 581):
   → Ποσό E3 = ABS(Υπόλοιπο)
   → Σύμβαση Χ/Π (K) καθορίζει αν είναι χρέωση ή πίστωση

ΠΡΟΣΟΧΗ: Για Ομάδα 7 (Έσοδα):
   - Υπόλοιπο είναι πιστωτικό (αρνητικό)
   - Ποσό E3 = ABS(Υπόλοιπο) → θετικό
   - Σύμβαση = "Πίστωση" (ενδεικτικό)
```

## Παράδειγμα Ολοκληρωμένης Σειράς

### Ενσώματο Πάγιο (Ομάδα 1)

```
Κωδικός: 113
Περιγραφή: Κτήρια
Ομάδα ΕΛΠ: 1
Χρέωση: 100000,00
Πίστωση: — (0,00)
Υπόλοιπο: 100000,00 (Χρεωστικό)
Τύπος Υπολοίπου: Χρεωστικό ✓

→ Κωδικός E3: 101 (Αξία Κτήσης Κτηρίων)
→ Πίνακας E3: Ν (Σειρά 1)
→ Σύμβαση Χ/Π: Χρέωση (αξία κτήσης)
→ Ποσό E3: 100000,00
```

### Σωρευμένες Αποσβέσεις (Ομάδα 1)

```
Κωδικός: 181
Περιγραφή: Σωρ. Αποσβέσεις κτηρίων
Ομάδα ΕΛΠ: 1
Χρέωση: — (0,00)
Πίστωση: 40000,00
Υπόλοιπο: -40000,00 (Πιστωτικό) ✓

→ Κωδικός E3: 101 (Σωρ. Αποσβέσεις - στη δ. στήλη του Ν)
→ Πίνακας E3: Ν (Σειρά 1)
→ Σύμβαση Χ/Π: Πίστωση (αποσβέσεις - αφαιρούνται)
→ Ποσό E3: 40000,00 (ABS(-40000,00))
```

### Αγορές Εμπορευμάτων (Ομάδα 2)

```
Κωδικός: 600
Περιγραφή: Αγορές εμπορευμάτων
Ομάδα ΕΛΠ: 2
Χρέωση: 180000,00
Πίστωση: — (0,00)
Υπόλοιπο: 180000,00 (Χρεωστικό) ✓

→ Κωδικός E3: 102 (Αγορές εμπορευμάτων χρήσης)
→ Πίνακας E3: Δ (1.2 - Αγορές χρήσης)
→ Σύμβαση Χ/Π: Χρέωση (κόστος αγορών)
→ Ποσό E3: 180000,00
```

### Πωλήσεις Αγαθών (Ομάδα 7)

```
Κωδικός: 700
Περιγραφή: Πωλήσεις αγαθών
Ομάδα ΕΛΠ: 7
Χρέωση: — (0,00)
Πίστωση: 250000,00
Υπόλοιπο: -250000,00 (Πιστωτικό) ✓

→ Κωδικός E3: 561 (Πωλήσεις αγαθών κατηγ. α-δ)
→ Πίνακας E3: Δ (2.1 - Έσοδα)
→ Σύμβαση Χ/Π: Πίστωση (έσοδα)
→ Ποσό E3: 250000,00 (ABS(-250000,00))
```

### Πελάτες (Ομάδα 3 - ΔΕΝ ΠΑΝΕ)

```
Κωδικός: 301
Περιγραφή: Πελάτες
Ομάδα ΕΛΠ: 3
Χρέωση: 60000,00
Πίστωση: 40000,00
Υπόλοιπο: 20000,00 (Χρεωστικό)

→ Κωδικός E3: -1 (ΔΕΝ ΜΕΤΑΦΕΡΕΤΑΙ)
→ Ποσό E3: — (κενό)
→ Σημείωση: Πελάτες δεν αναλύονται σε E3
```

## Σημαντικές Σημειώσεις

✅ **Διπλογραφία**: Ακολουθούμε ΑΥΣΤΗΡΑ τους κανόνες χρέωσης/πίστωσης
✅ **Ομάδες 3, 4, 5**: Δεν πάνε στο E3 (μόνο Ισολογισμό σε διπλογραφικά)
✅ **Ομάδες 1, 2, 6, 7**: Πάνε κανονικά στο E3
✅ **Ομάδα 0**: Ειδικός χειρισμός (πληροφοριακοί - Πίνακας Ε αν χρειάζονται)
✅ **Αποσβέσεις**: Πάντα πιστωτικό υπόλοιπο, ίδιος κωδικός E3 με το πάγιο
✅ **Απόλυτες τιμές**: Ποσό E3 = ABS(Υπόλοιπο)
